Listing your project on Grainlify puts its issues in front of people looking for work, and gives you one place to decide who does it. This page takes you from nothing to your first assigned issue. Each step links to a page with the detail.

![Maintainer quick start](video:maintainers "1:24")

## Before you start

- A Grainlify account, signed in with GitHub. See [Create your account](/docs/create-your-account).
- A public repository you can install GitHub apps on.

Your maintainer tools live in the same account as your contributor ones. You switch between them with **CONTRIBUTOR** and **MAINTAINER** in the header. See [Contributor, maintainer and admin views](/docs/views).

![The header, with MAINTAINER selected](shot:maint-role-switcher?desktop "Switching to the maintainer view")

## From install to first assignment

1. **Switch to MAINTAINER.** This opens **Maintainers**, with the **Dashboard**, **Issues**, **Pull Requests** and **Bounties** tabs.
2. **Install the GitHub App.** Choose **Select repositories**, then **Add a repository**, then **Install GitHub App**. On GitHub, pick the repositories you want on Grainlify. [Add your repositories](/docs/maintainers/add-repositories)
3. **Come back and switch to MAINTAINER again.** GitHub returns you to **Discover**. Switch to **MAINTAINER** and the **New Project Setup** window opens for your new repository.
4. **Finish setup.** Add a description and choose an ecosystem, then **Save & Continue**. Your project is now listed for contributors. [Finish project setup](/docs/maintainers/project-setup)
5. **Tell people.** Optionally, if your account has the button for it, post a comment on an issue as the Grainlify app to say it's open for applications. [Post a Grainlify bot message](/docs/maintainers/bot-message)
6. **Wait for applications.** You get a notification when someone applies. The **Dashboard** shows what's changed in the last seven days. [Your maintainer dashboard](/docs/maintainers/maintainer-dashboard)
7. **Assign someone.** In **Issues**, open the issue, expand an application, and choose **Assign**. Grainlify assigns them on GitHub and lets them know. [Review applications](/docs/maintainers/managing-applications)

   ![An application expanded, with the Assign button](shot:maint-quickstart-assign?desktop "Your first assignment")

8. **Review the pull request on GitHub.** Follow it from the **Pull Requests** tab and merge it on GitHub as usual. [The pull requests feed](/docs/maintainers/reviewing-pull-requests)
