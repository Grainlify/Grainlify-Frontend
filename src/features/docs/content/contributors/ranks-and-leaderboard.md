Your rank is a public record of the work you've landed on Grainlify. This page explains how your position is counted, what each tier means, and how to read the leaderboard. Open it from **Leaderboard** in the rail.

## How your position is counted

Your score is the number of pull requests you've had merged into projects listed on Grainlify in the last 90 days.

| Counts | Doesn't count |
| --- | --- |
| A pull request you authored that was merged | A pull request that's still open, or was closed without merging |
| …into a project listed on Grainlify | Issues you opened or commented on, and reviews you left |
| …merged within the last 90 days | Pull requests into a repository that is a fork |
| | Accounts whose GitHub login ends in `[bot]` |

- **Every merged pull request is worth 1.** Size, difficulty and repository make no difference.
- **Ties are ordered alphabetically** by username.
- **Your username is matched without regard to case**, so two spellings of your login count as one person.
- **The 90 days roll.** It always means the 90 days up to now, not a season with a start date.

## Rank tiers

Your position places you in a tier, shown on the rank card on your profile.

| Tier | Position |
| --- | --- |
| Conqueror | 1–5 |
| Ace | 6–10 |
| Crown | 11–20 |
| Diamond | 21–50 |
| Gold | 51–100 |
| Silver | 101–500 |
| Bronze | 501 and below |
| Unranked | No merged pull requests in the window |

Your tier can go down as well as up, because it follows your position.

## This season and all time

The board opens on **This season**: merged in the last 90 days. **All time** counts every merge on record, under the same rules.

![The leaderboard showing Seasonal Contributors, with This season selected](shot:leaderboard-season "Leaderboard, this season")

The rank card on your profile shows your position and tier this season, and your all-time tier and position on the line beneath. If your merges are all older than 90 days, it says **Unranked** this season and still shows where you stand all time.

![The rank card on a profile, with the all-time line](shot:profile-rank-card "Your rank card")

## Contributors and Projects

The toggle at the top switches between **Contributors** and **Projects**. The Projects board ranks organisations by how many different people had a pull request merged into their repositories, over the same window and under the same rules. Someone who contributes to three repositories in one organisation counts once. Ties go to the organisation with more merged pull requests, then by name.

![The Projects leaderboard](shot:leaderboard-projects "Top Projects")

## Filter by ecosystem

The **All Ecosystems** dropdown limits either board to one ecosystem. Only merges into that ecosystem's projects count, and positions are worked out again for that ecosystem alone, so your place there usually differs from your place overall.

![The ecosystem dropdown open on the leaderboard](shot:leaderboard-ecosystems "Filter by ecosystem")

Choose a contributor in the table to open their profile.

> [!NOTE]
> Rank is a public record, not money. It doesn't change your chances in a bounty or GrainHack draw, and it doesn't affect any payout.
