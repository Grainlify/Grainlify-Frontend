Every limit you might run into on Grainlify, in one place. Some limits are fixed. Others are settings that Grainlify can change, and for those this page says what is limited and where the live value is published, so you never plan around a number that has moved.

## Where live values are published

| Programme | Where to read the live rules |
| --- | --- |
| Grainlify Bounties | [grainlify.com/bounties/rules](/bounties/rules). Public, no sign-in needed. Each value shows its default, and who changed it if it was changed. |
| GrainHack and the Founding Contributor Pool | **My GrainHack → Rules** in the app. It shows the defaults that apply to new events. An event keeps the rules it had when it went live, even if a default changes later. |

## Fees

Grainlify doesn't charge contributors or maintainers anything. Browsing, applying and listing a repository are free.

For a GrainHack event, a platform fee can be taken from the sponsor's total before the event's pools are set. The rate is a published setting, under **Platform fee** in **My GrainHack → Rules**.

Linking a Solana wallet or registering a payout address means signing a message, which costs nothing and moves no funds.

## Bounties

| What is limited | Fixed or setting | Where it applies |
| --- | --- | --- |
| One Solana wallet per GitHub account, and one GitHub account per wallet | Fixed | Linking a wallet. A new wallet replaces the old one. |
| The message you sign to link a wallet expires after ten minutes | Fixed | Linking a wallet |
| Past wins raise your tickets for your first two completed bounties only | Fixed | The draw |
| Minimum GitHub account age to apply | Setting, on [/bounties/rules](/bounties/rules) | Applying |
| Whether you need a linked wallet before applying | Setting, on [/bounties/rules](/bounties/rules) | Applying |
| How many bounties you can hold at once | Setting, on [/bounties/rules](/bounties/rules) | Applying and the draw |
| Whether members of the repository's own organisation can apply | Setting, on [/bounties/rules](/bounties/rules) | Applying |
| How long applications stay open, and how often an empty window is extended | Setting, on [/bounties/rules](/bounties/rules) | The application window |
| How long a winner has to open a pull request | Setting, on [/bounties/rules](/bounties/rules) | Your assignment |
| The note you can add when applying: optional, up to 2,000 characters | Fixed | Applying |

## GrainHack

All of these are settings, published in **My GrainHack → Rules**.

| What is limited | Where it applies |
| --- | --- |
| Minimum GitHub account age, and whether you need a commit from before the event was announced | Applying |
| How many applications you can have open at once | Applying |
| How many assignments you can hold at once (your slots), and when a slot is freed | Assignments |
| How many issues you can win from one organisation, and across the whole event | The draw |
| How long you have to open a qualifying pull request before the assignment is released | Your assignment |
| How many abandons lock you out of new assignments in an event | Your assignment |
| How long after the event ends a merge still counts | Results |
| How long the appeal window stays open | Appeals |
| How many issues one organisation can enter into an event | Maintainers labelling issues |

Past wins raise your tickets for your first two completed GrainHack issues only. That one is fixed, and the Rules page states it too.

## Founding Contributor Pool and referrals

| What is limited | Fixed or setting | Where to read it |
| --- | --- | --- |
| The size of the pool, the shares each action earns, and the size and multiplier of each wave | Setting | **My GrainHack → Rules**, under **Founding pool** |
| A lifetime cap on shares from referrals who only verified | Setting | **My GrainHack → Rules**, under **Founding pool** |
| A referral counts only if the person signs up within 30 days of clicking your link | Fixed | **Settings → Referrals** |

## Uploads and messages

| What is limited | Limit | Where it applies |
| --- | --- | --- |
| Application message for an issue | Required, up to about 5,000 characters | Applying for an issue |
| Social follow screenshots | One for LinkedIn and one for X, submitted together, each under 5 MB | **Settings → Rewards** |
| Profile picture | SVG, PNG, JPG or GIF, under 5 MB | **Settings → Profile** |
| Help request message | Up to 2,000 characters | **Get help** and [/support](/support) |
| Help request screenshot | Up to 2 MB | **Get help** and [/support](/support) |
| Bot message on an issue | Up to about 32,000 characters | Maintainers posting as the Grainlify bot |
| Organisation links | Up to 200 characters each | Maintainers editing an organisation page |
