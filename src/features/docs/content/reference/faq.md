Short answers to the questions people ask most when they start. Each one links to the page with the full story.

## Getting started

**Does Grainlify cost anything?**
No. Browsing, applying for issues and listing your repositories are free for contributors and maintainers. See [Limits, caps and fees](/docs/reference/limits).

**Do I need a password?**
No. You sign in with your GitHub account, and the first sign-in creates your Grainlify account. See [Create your account](/docs/create-your-account).

**Do I need a crypto wallet?**
Not to browse, apply or contribute. You need one only to be paid: a Solana wallet for bounties, and an Ethereum wallet for a Base payout address for GrainHack. Payouts on Aptos, which use a Petra wallet, are built but not switched on yet. See [Supported wallets and chains](/docs/reference/wallets).

**Can I use Grainlify on my phone?**
Yes. The header's controls move into the menu behind the button at the top right, and you can link a Solana wallet from your phone too. See [Find your way around](/docs/find-your-way-around).

## Working on issues

**How do I get an issue to work on?**
Apply for it. On an ordinary issue the maintainer chooses who works on it. Bounties and GrainHack issues are assigned by a weighted draw when the application window closes. See [Apply for an issue](/docs/contributors/applying-to-issues).

**Is a bounty first come, first served?**
No. Applications stay open for a set window, then one applicant is drawn. Applying early gives you no advantage. See [Apply for a bounty](/docs/contributors/apply-for-a-bounty).

**What does the draw look at?**
For a bounty, the weights published on [/bounties/rules](/bounties/rules), such as fit for the issue and whether you've won before. It never looks at your follower count, stars, total pull requests or merge rate. See [Apply for a bounty](/docs/contributors/apply-for-a-bounty). GrainHack has its own draw: see [The draw: tickets and weights](/docs/contributors/grainhack-draw).

**Can I link more than one Solana wallet?**
No. Each GitHub account has one wallet, and each wallet belongs to one GitHub account. Linking a new wallet replaces the old one. See [Link your Solana wallet](/docs/contributors/link-solana-wallet).

## Maintainers

**How do I become a maintainer?**
Add your repositories with the Grainlify GitHub App. Owning a project on Grainlify is what lets you manage its applications. See [Add your repositories](/docs/maintainers/add-repositories).

**I switched to maintainer view. Why can't I assign anyone?**
The view only changes what you see. The **Assign** and **Reject** controls appear on issues in projects you own. See [Contributor, maintainer and admin views](/docs/views).

## Rewards and standing

**Why does my profile say I'm unranked?**
Your rank counts pull requests merged in the last 90 days on projects listed on Grainlify. If you have none in that window, you're unranked this season, even if you have an all-time rank. See [Ranks and the leaderboard](/docs/contributors/ranks-and-leaderboard).

**What happened to my points?**
The points programme was retired, and the Founding Contributor Pool replaced it. See [What changed](/docs/what-changed).

**Where are the GrainHack rules?**
In the app, under **My GrainHack → Rules**. Every value there is live, so it's the one to trust over any number you read elsewhere. See [What GrainHack is](/docs/contributors/grainhack).

## Getting help

**Something's broken. Who do I tell?**
Choose **Get help**, the last icon on the rail. If you can't sign in, use [grainlify.com/support](/support), which works without an account. See [Get help](/docs/contributors/getting-help).
